# MindTree Technology Solution

Official website source code for **MindTree Technology Solution**, built with Django and deployed using CloudLinux Passenger.

## About

MindTree Technology Solution delivers technology and digital transformation solutions designed to help organisations modernise operations, strengthen infrastructure and adopt innovative technologies.

Our areas of focus include:

- Cloud Computing
- Cybersecurity
- Artificial Intelligence
- Enterprise Software
- IT Infrastructure
- Automation
- Data Analytics
- Digital Transformation
- Smart Agriculture & AgTech

## Technology Stack

The website is built using:

- Python
- Django
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- CloudLinux Passenger
- cPanel Hosting

## Website Pages

The current website includes:

- Home
- About
- Services
- Solutions
- Projects
- Innovation
- Contact

The homepage also features a responsive carousel highlighting:

1. Digital Transformation
2. Cloud, AI & Cybersecurity
3. Smart Agriculture & AgTech
